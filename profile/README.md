## Apps

  [Web](https://manul-wizard.github.io/interval-apps/tabata/) · [RuStore](https://www.rustore.ru/catalog/app/com.LLarean.TabataTimer)
- **[Japanese Walking](https://github.com/manul-wizard/interval-apps/tree/main/apps/walking)** — 3 minutes fast, 3 minutes slow, with your own music for each pace.<br>
  [Web](https://manul-wizard.github.io/interval-apps/walking/)

No ads, no account, no tracking. Source code and Android test builds: [interval-apps](https://github.com/manul-wizard/interval-apps).
